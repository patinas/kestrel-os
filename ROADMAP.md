# Roadmap

1. **Foundations (now):** architecture, ADRs, repo layout.
2. **First boot:** mkosi x86_64 image that boots into Chromium on the
   compositor in a VM, read-only system image.
3. **Hardware:** kestrel-hwdetect, GPU driver selection (AMD, Intel, NVIDIA),
   Wi-Fi/Bluetooth/audio, test matrix on real machines.
4. **Shell v1:** launcher, shelf, quick settings, settings app, setup wizard,
   lock screen - to the design system.
5. **Updates and lockdown:** A/B sysupdate, dm-verity, signed UKIs,
   developer mode, powerwash.
6. **Gaming mode:** gamescope session, Steam + Proton, PRIME offload.
7. **ARM:** Raspberry Pi 4/5 image.
8. **Public alpha.**
