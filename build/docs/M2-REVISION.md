# M2 revision notes
Fixes vs first draft: installer is VM-only (vd*/loop/QEMU model guard, refuses running disk, mounted disks, needs KESTREL_ALLOW_VM_INSTALL=yes and KESTREL_CONFIRM='ERASE <dev>'); builds the root tree once, applies the Kestrel overlay and user, populates BOTH slots; root ro via cmdline only, /var and /home on writable kdata; kernel+initramfs per slot on the ESP (/A, /B). Updater requires a minisign-verified image, derives the active slot from cmdline + mounted label, checks slots and ESP are on the same VM disk, writes by verified device path, cleans up on failure, arms 3-try boot. GPU selector runs as a root systemd oneshot. kestrel-mode uses two exact-name pkill calls.
Still untested; test only on a blank QEMU disk. Needs systemd-bless-boot wiring (kestrel-health.target) from docs/UPDATES.md before the 3-try fallback is real. Update.sh arms the new slot as default - a failed first-boot fallback depends on that wiring.

Execution guard: scripts require a QEMU guest and a virtio disk serial KESTREL_TEST_ONLY. Do not run them on a host or ordinary VM disk. Source is experimental and not yet install/update tested. No automatic rollback claim is valid until health/bless integration and reboot tests pass.
